# role-base-access-control-demo

A basic Python demo of role-based access control (RBAC) using fictional users.

## What it does
- Defines roles (admin, editor, viewer) and their permissions
- Has a `has_permission()` function to check access
- Tests the system with fictional users: nina, joy, emerald, tobe, erica

## Run it
python rbac_demo.py
